# SalonMall

Marketplace تخصصی محصولات و تجهیزات آرایشگاهی ایران.

## Product direction
- Central product catalog
- Multi-vendor offers per product
- Seller storefronts
- Price comparison
- Unified cart
- Seller commissions and settlement ledger
- Image search / camera-assisted product matching
- RTL Persian-first UX
- Mobile-first responsive design
